# 🚀 RecruitAI — AI-Powered Resume Screener

> Paste a job description, upload resumes, and get candidates ranked by AI similarity in seconds.

---

## 📌 What Does This Project Do?

RecruitAI reads a job description you type in and automatically ranks resumes from best match to worst. Instead of scanning hundreds of CVs by hand, the AI reads the *meaning* of text — so "Python engineer with cloud experience" will match a resume that says "software developer skilled in AWS and Django," even without exact word overlap. You get a ranked list of candidates with similarity scores so you can focus on the top results immediately.

---

## ✨ Features

- **Semantic resume matching** — Understands meaning, not just keywords
- **Upload your own resumes** — Drag and drop PDF or Word (.docx) files
- **Bulk upload** — Score dozens of resumes at once
- **Skill extraction** — Automatically identifies key skills from job descriptions
- **Ranked results** — Candidates sorted by match score with visual bars
- **25+ job categories** — Pre-loaded dataset of 2,484 real resumes
- **Clean web interface** — No coding needed to use the app
- **REST API** — Developers can connect it to other systems
- **Docker support** — Deploy everything with one command

## 🛠️ Installation — Step by Step

### Option A — Docker (Easiest, Recommended for Beginners)

**Step 1 — Download the project**

```bash
git clone https://github.com/your-username/recruitai.git
cd recruitai
```

**Step 2 — Copy the settings file**

```bash
# Mac / Linux
cp .env.example .env

# Windows
copy .env.example .env
```

**Step 3 — Build and launch everything**

```bash
docker-compose up --build
```

> The first build downloads ~500 MB of AI model files and Python packages. This can take 5–15 minutes depending on your internet speed. Subsequent starts are fast.

**Step 4 — Open the app**

| What | Address |
|------|---------|
| Web app | `http://localhost:3000` |
| API docs | `http://localhost:8000/docs` |
| Health check | `http://localhost:8000/api/health` |

---

### Option B — Manual Setup (Without Docker)

**Step 1 — Download the project**

```bash
git clone https://github.com/your-username/recruitai.git
cd recruitai
```

**Step 2 — Create a virtual environment**

A virtual environment keeps this project's packages separate from the rest of your computer.

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Mac / Linux
python -m venv venv
source venv/bin/activate
```

You will see `(venv)` appear at the start of your terminal prompt. This means it worked.

**Step 3 — Run the Jupyter notebooks (one-time setup)**

```bash
cd notebook
pip install -r requirements.txt
jupyter notebook
```

Your browser will open Jupyter. Run the notebooks **in this exact order**:

1. Open `01_EDA_and_Preprocessing.ipynb` → click **Kernel → Restart & Run All**
2. Open `02_Model_Training_and_Evaluation.ipynb` → click **Kernel → Restart & Run All**

This takes 5–10 minutes. When finished, check that these files exist:

```
backend/models/saved/
├── resume_embeddings.pkl
├── resume_data.pkl
└── bert_model/
```

**Step 4 — Install backend packages**

```bash
cd ../backend
pip install -r requirements.txt
```

**Step 5 — Copy the settings file**

```bash
# Mac / Linux (from the recruitai/ folder)
cp .env.example .env

# Windows
copy .env.example .env
```

**Step 6 — Start the backend server**

```bash
uvicorn main:app --reload --port 8000
```

You should see this message:

```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

**Step 7 — Open the web app**

Open the file `frontend/index.html` directly in your browser. Or go to `http://localhost:8000/docs` to use the API through your browser.

## 🌐 Environment Variables

These settings live in your `.env` file. Copy `.env.example` to `.env` to create it. You usually do not need to change the defaults.

| Variable | What it does | Default value |
|----------|--------------|---------------|
| `MODEL_PATH` | Where the AI model weights are saved | `models/saved/bert_model` |
| `EMBEDDINGS_PATH` | Where the pre-computed resume vectors are saved | `models/saved/resume_embeddings.pkl` |
| `DATA_PATH` | Where the resume text and category data is saved | `models/saved/resume_data.pkl` |
| `MAX_FILE_SIZE_MB` | Largest resume file the app will accept | `10` |
| `TOP_K_RESULTS` | How many top candidates to show per search | `10` |

## 📓 Jupyter Notebooks

The `notebook/` folder contains two notebooks. You only need to run these **once** when setting up the project. After that, the model files are saved to disk and the backend loads them automatically.

| Notebook | What it does | How long it takes |
|----------|-------------|-------------------|
| `01_EDA_and_Preprocessing.ipynb` | Loads 2,484 real resumes from CSV, removes noise (stopwords and symbols), explores category distribution, and saves cleaned data | ~1 minute |
| `02_Model_Training_and_Evaluation.ipynb` | Converts every cleaned resume into a 384-number AI vector using BERT, measures how accurate the matching is (74% Precision@5), and saves the model files | ~5–10 minutes |

**To run the notebooks:**

```bash
cd notebook
pip install -r requirements.txt
jupyter notebook
```

Click on a notebook in the Jupyter file browser, then go to **Kernel → Restart & Run All**.

> **What is a "vector"?** It is a list of numbers that captures the *meaning* of text. The AI converts sentences into these number lists so that similar sentences end up with similar numbers — that is how matching works.

---

## 🧠 How It Works

- **Resumes are prepared in advance** — The Jupyter notebooks read 2,484 resumes and convert each one into a list of 384 numbers (called an embedding) that captures its meaning. These are saved to disk so the backend loads them instantly at startup.
- **You type a job description** — For example: *"Senior Python developer with FastAPI and Docker experience"*
- **The AI reads your job description** — Your text is also converted into a 384-number embedding using the same AI model (`all-MiniLM-L6-v2`, a fast and accurate BERT variant)
- **Similarity is calculated** — The app measures how close your job description embedding is to every resume embedding using a formula called cosine similarity — the closer, the better the match
- **Results are ranked and displayed** — Resumes are sorted from highest score (best match) to lowest, and the top candidates are shown with their score and a preview snippet

## ❓ Common Issues & Fixes

| Problem | Solution |
|---------|---------|
| `"embeddings file not found"` error on startup | Run `02_Model_Training_and_Evaluation.ipynb` first to generate the model files, then restart the server |
| Resume upload fails immediately | Check that your file is `.pdf` or `.docx` and is smaller than `MAX_FILE_SIZE_MB` (default: 10 MB) |
| Backend server will not start | Make sure you ran `pip install -r backend/requirements.txt` and that Python 3.9+ is active |
| Results look wrong or scores are all the same | Delete `backend/models/saved/` and re-run both notebooks from scratch |
| CORS error appears in the browser console | The backend must be running on port 8000 before you open the frontend |
| Docker build fails halfway | Ensure Docker Desktop is running and you have at least 3 GB of free disk space |
| Jupyter notebook runs very slowly | Normal on first run — the AI model (~90 MB) is being downloaded from the internet |
| `ModuleNotFoundError` for any package | Make sure your virtual environment is activated and you ran `pip install -r requirements.txt` |
