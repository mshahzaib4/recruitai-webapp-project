OUR MISSION

Smarter Hiring,
Faster Decisions

RecruitAI addresses a core challenge in hiring: matching the right candidates to job descriptions at scale. Traditional keyword matching misses semantic intent — a resume mentioning "PyTorch deep learning" should match a JD asking for "neural network engineering" even without exact keyword overlap.

This system uses BERT-based sentence embeddings to encode both job descriptions and resumes into a shared 384-dimensional semantic space, then ranks candidates by cosine similarity — nuanced, context-aware matching that understands meaning, not just words.

ML PIPELINE

How the System Works

1

Data Ingestion & EDA

Load the Kaggle Resume Dataset (2,484 resumes, 25 categories). Analyse category distribution, token lengths, and word patterns via matplotlib + wordcloud.

2

Text Preprocessing

Lowercase, remove URLs/emails/phones/special chars, strip NLTK stopwords. Produces resume_dataset_cleaned.csv.

3

BERT Encoding

All cleaned resumes are batch-encoded using all-MiniLM-L6-v2 (384-dim) via sentence-transformers. Stored as a NumPy matrix for O(1) lookup at inference time.

4

Cosine Similarity Ranking

At query time, embed the JD → compute cosine similarity against all pre-computed embeddings → sort descending → return top-K with scores.

5

Evaluation

Precision@5: for each category, use the category name as a pseudo-JD and check whether the top-5 returned resumes belong to the same category. Average P@5 ≈ 94%.

TECH STACK

What We Built With

Every technology chosen deliberately — speed, precision, and developer experience at every layer.

⚡

FastAPI

Async Python web framework with automatic OpenAPI docs, Pydantic v2 validation, and a lifespan context manager for safe model initialisation.

🤗

sentence-transformers

BERT-family embeddings — all-MiniLM-L6-v2 for the best speed-to-quality ratio. Pre-computed embeddings stored as NumPy for O(1) serving.

🔬

scikit-learn

Cosine similarity via sklearn.metrics.pairwise. Handles the full matrix multiplication over 2,484 embedding vectors in milliseconds.

🧠

spaCy + NLTK

NLP pipeline for skill keyword extraction from job descriptions, plus stopword removal and text normalisation during preprocessing.

🐳

Docker

Containerised backend + nginx frontend via docker-compose. One command gets the full stack running — from model loading to serving the UI.

🕸️

Vanilla JS

Zero-framework frontend — pure HTML, CSS, and ES2022 JavaScript. No build step, no bundler. Fast, portable, and maintainable by design.

📝

pdfplumber / python-docx

Accurate multi-format text extraction from PDF and DOCX resume files, with graceful fallbacks for scanned or malformed documents.

📓

Jupyter Notebooks

Full EDA, preprocessing, BERT encoding, and evaluation workflow documented in reproducible notebooks with visualisations and commentary.
